# Portfolio site

## Adding a post
1. Name the PDF `YYYY-MM-DD Title of the post.pdf`, for example `2026-11-20 Idle economy pacing.pdf`.
2. Optional: add `YYYY-MM-DD Title of the post.txt` with a one-line summary.
3. On GitHub, open the `writing` folder, click **Add file → Upload files**, drop the file(s) in, and click **Commit changes**.
4. Refresh the site. The post appears on the home page and on the Writing page.

To remove or rename a post, delete or rename the PDF in `writing/` the same way.

## First-time setup
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload everything in this folder to it.
3. Settings → Pages → Source: Deploy from a branch, Branch: main, folder / (root) → Save.
4. The site is at `https://YOUR-USERNAME.github.io` a minute later.

## Preview on your computer
Double-click `Open site.bat` instead of `index.html`. It picks up any new PDFs in `writing/` and opens the site.
